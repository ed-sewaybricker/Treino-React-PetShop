# Petshop — Projeto de Treino em React

## Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos em **React**, com o objetivo de praticar a criação de páginas web e a organização de componentes.

A aplicação simula um site de petshop, contendo páginas com informações sobre o estabelecimento e funcionalidades básicas de navegação.

## Páginas do projeto

- **Página Inicial:** apresentação do petshop.
- **Cadastro de Pet:** formulário para registrar informações dos animais.
- **Contatos:** informações e meios de contato do estabelecimento.
- **Sobre Nós:** apresentação da história e dos objetivos do petshop.

## Tecnologias utilizadas

- React
- JavaScript
- HTML
- CSS

## Objetivo

Praticar os conceitos fundamentais do React, desenvolver interfaces com componentes reutilizáveis e aprimorar meus conhecimentos em estilização CSS e criação de páginas web.
